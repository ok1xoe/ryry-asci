# RYRY TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Konzolová aplikace `ryry-tui` s ASCII/Unicode art rozhraním, ovládáním co nejpodobnějším GUI RYRY a myší v příjmovém okně.

**Architecture:** Nová knihovna `TUIKit` (obecná terminálová vrstva: buňková mřížka, diferenční vykreslení, parser vstupu, režim terminálu, detekce schopností) a knihovna `RYRYTUI` (pohledy, rozložení, klávesová mapa, smyčka aplikace nad stávajícím `AppModel` z `AppUI`) a tenký spustitelný cíl `ryry-tui`. Jádro (Engine, modem, log, makra, spoty) se nemění. Pohledy kreslí do `ScreenBuffer` jako čisté funkce stavu, takže jdou testovat snapshotem bez terminálu.

**Tech Stack:** Swift 6, Swift Testing, Darwin (termios, ioctl, signal), stávající moduly balíčku (`AppUI`, `AppCore`, `Engine`, `Settings`, `QSOLog`, `Spots`, `ModemKit`, `Localization`).

**Spec:** `docs/superpowers/specs/2026-11-09-ryry-tui-design.md`

## Global Constraints

- Jádro a stávající moduly se nemění (výjimka: aditivní `public` v `AppUI`/`Settings`, pokud je nutné); 830 stávajících testů musí dál procházet.
- Minimální velikost terminálu 100×32; menší → hláška „Terminal too small (need 100×32)“, ne pád.
- Žádný terminál není referenční: barvy true color → 256 → 16 → mono, Unicode půlbloky → ASCII, myš volitelná (vše i klávesnicí).
- Každá akce má klávesu, která funguje i bez ⇧F-kláves a modifikátorů: ⇧F1–⇧F4 = také Alt+1–Alt+4.
- ⌘ → Ctrl; Esc = okamžitě RX; Ctrl+T TX/RX; Ctrl+L zalogovat; okna Alt+L (Log), Alt+S (Spoty), Alt+B (Band mapa), Alt+C (Skóre), Alt+M (Multiplikátory) a Ctrl+O = nabídka oken (pro terminály bez Alt); Ctrl+P nastavení; Ctrl+G nápověda; Ctrl+Q konec. Nepoužívat kombinace, které terminál nedoručí nebo které kolidují s řídicími bajty (Ctrl+M = Enter, Ctrl+I = Tab, Ctrl+H = Backspace, Ctrl+, a Ctrl+číslice).
- TUI a GUI nepoběží najednou: při obsazeném zvuku/portu/API srozumitelná hláška a konec (exit kód 1).
- `settings.json` se zapisuje zpět a **zachová pole, která TUI nezná**; log a data ve stejných formátech a složkách jako GUI.
- Vykreslování nesmí blokovat engine; frekvence překreslení nejvýš 15 Hz plus okamžitě po vstupu.
- Po jakémkoli ukončení (konec, Ctrl-C, SIGTERM/SIGHUP, chyba) se obnoví terminál (alternativní obrazovka, kurzor, myš, raw režim).
- Veškerý externí text (příjem, spoty z telnetu, callbook) se před vykreslením čistí od řídicích znaků a escape sekvencí.
- Testy deterministické, bez závislosti na čase a skutečném terminálu (CI běží sériově na 3 jádrech).
- Příkazy: `export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`, potom `swift build`, `swift test --filter <Cíl>`.
- Commity jen na větvi `ryry-tui`, zakončené řádkem `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. **Nepushovat** (origin je původní repozitář RYRY).

## Review Focus

1. Escape sekvence v externím textu (spot z telnetu, příjem) nesmí ovládat terminál → test v Task 12 a 14 (`sanitize`).
2. Terminál menší než 100×32 nebo změna velikosti za běhu (SIGWINCH) → test v Task 8 (`compute` vrací `nil`) a v Task 13.
3. Vstup není TTY (roura, zavřený stdin) → `ryry-tui` hlásí chybu a končí → Task 13.
4. Široké znaky, kombinující znaky a dlouhé řádky bez mezer v příjmu nesmí rozhodit mřížku → Task 2 a 10.
5. Pozastavení (Ctrl+Z/SIGTSTP) a návrat (SIGCONT) obnoví terminál a překreslí → Task 5 a 13.
